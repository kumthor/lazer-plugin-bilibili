# v0.6.1 — ASMR 槽写具体词，不再一律扁平 `ASMR`

用户 2026-11-24：「没必要都改成 asmr，标签更准更有代表性更好。」

v0.6.0 让 ASMR 槽一律写 `ASMR`，解决了与短/长通道的标签相撞，但把线上已有的信息埋掉了：三个词加 `tag` 字段本来就能区分 `助眠` / `白噪音` / `哄睡` / `环境音`，而 `白噪音 · 20:11` 比 `ASMR · 20:11` 严格更有用。

## 判据：位置，不是优先级表

**标题里最早出现的那个标记词胜出**；标题一个标记词都没有时，才由 `tag` 字段决定；两者都没有则退回 `ASMR`（伞词）。

标记词表（与 v0.6.0 的 `ASMR_TAG` 同序同内容，一个字没动）：
`asmr` / `助眠` / `白噪音` / `白噪声` / `哄睡` / `环境音` / `睡眠`。

标签映射：`白噪声` → `白噪音`（同义归并）；`睡眠` → `助眠`（61 行里只出现 1 次，单独成标签只会是一次性噪声）。

**不再退回线上分区名**：`21 日常` 在卡片上没有信息量，`音乐综合`/`人文历史` 会与短/长通道自己的标签相撞（那正是 v0.6.0 修的问题），而且 `tid=21` 的 `view.tname` 在真站是空串。

## 四种判据的实测分布（61 行去重 ASMR 候选）

| 判据 | 分布 |
| :--- | :--- |
| **本轮：标题最早出现的词，缺失时用 tag** | `{ASMR:24, 助眠:20, 白噪音:17}` |
| 对照 A：固定优先级（白噪音优先） | `{助眠:29, ASMR:9, 白噪音:22, 哄睡:1}` |
| 对照 B：只看标题，无词退回扁平 ASMR | `{ASMR:49, 助眠:6, 白噪音:6}` |
| 对照 C（v0.6.0）：一律扁平 ASMR | `{ASMR:61}` |
| 线上分区名（v0.6.0 修掉的写法） | `{日常:52, 音乐综合:6, 人文历史:2, 鬼畜剧场:1}` |

对照 B 会把 49 行标成 `ASMR`，其中 **22 行其实在 `tag` 里自报 助眠/白噪音** —— 那正是用户要的那部分信息。对照 A 与本轮在 17 行上给出不同答案，且需要维护一张优先级表；位置判据不需要，且与阅读顺序一致。

## 验证

- 契约测试 **177 条**（v0.6.0 的 173 条里改写 3 条 → 新增 4 条 T17）。
- 负向控制 **N1–N4 全部按预期变红**，还原后 byte-identical，基线回到全绿：
  - N1 标签退回扁平 `ASMR` → `T17#01`（连带 `#02`/`#03` 与 T16 三条）
  - N2 去掉 tag 回退（只看标题）→ `T17#03`（单独）
  - N3 位置判据换成固定优先级 → `T17#02`（单独）
  - N4 ASMR 槽回退到线上分区名 → `T17#04`（连带 `#01`/`#02`/`#03` 与 T16 三条）
- 打包 15/15 逐字节一致，安装 15/15 md5 一致。
- 真机：16 格里 **8 个 ASMR 槽分成 助眠×3 / ASMR×2 / 白噪音×3**，bvid 零重复。
- 真站逐条核对：ASMR 槽 **8/8 一致**，判据给出的每个名字都能在真站 `title`/`tag` 里找到出处。

**N4 第一次是假绿的，原因不在被测代码**：负向控制脚本原来按 `flutter test` 末尾的 `Failing tests:` 段解析失败清单，而那段超过 4 条就写成 `... and 3 more`。N4 打红了 7 条，目标 `T17#04` 恰好被截断在清单外，脚本因此报 FAIL。改成解析 `[E]` 行（失败当场打印，不受截断影响）后四条全过。这个缺陷同时会让**任何**连带超过 4 条的负向控制读错。

## 一处刻意不改

`ASMR_TAG` 的标记词表与 v0.6.0 完全一致，一个字都没动。本轮改的是**标签怎么取名**，不是**谁能进 ASMR 通道**——后者有 `T16#06`（21 必须带标记）与 `T16#07`（真实分区的跨界行）钉着，动它会连带改变上架集合，超出这次的要求。

## 遗留

- **真站样本是滚动的**：`R2` 的核对只能核当轮货架上还在的 bvid。第一次跑时三个词的 `page_size=30` 窗口已经翻过一轮，8 个槽一个都没复现，于是改成「先跑活体探针、立刻跑核对」的串联执行，才拿到 8/8。这不是判据的问题，是 `order=pubdate` 的窗口只有十几分钟的必然结果。
- **`睡眠` 归并到 `助眠`** 是取舍不是实测结论：61 行里它只出现 1 次，样本量不足以支撑一个独立标签。若将来它变成高频词，改 `ASMR_LABEL_BY_TAG` 一行即可。
