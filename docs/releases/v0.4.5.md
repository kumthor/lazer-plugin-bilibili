# v0.4.5 — 多 P 视频的专辑名与入口可见性

多 P 视频在列表里占一行，点它就只播 P1——这是宿主把「页面列表」直接当播放队列的结果（`home_pages.dart:258`），插件无法在队列层拆分。以前也看不出「这里能选 P」：所有视频的专辑名都是同一个泛名 `B站视频`，而**正在播放页的专辑名是唯一不依赖列表的分 P 入口**。

## 改动

### 1. 专辑名 = `视频标题 · N P`

`N` 按行的可得性取，**不猜**：

| 行来源 | N 取自 | 实测 |
|---|---|---|
| `popular` / `ranking` / `related` / `space.arc` | 行内 `videos` | 20/20、97/97、40/40、有 |
| `view`（`song` / `albumSongs`） | `view.pages` 的条数 | 与 `videos` 一致 |
| `search` | 无（真机 0/20） | 写纯标题 |
| 收藏夹 | 无（真机 0/19） | 写纯标题 |

**后缀只给多 P（`N ≥ 2`）加。** 单 P 加 ` · 1 P` 只让专辑列与标题列更像重复的一行字，而 1 P 的视频本来就没有 P 可选。`albumId` 始终是 `bvid`，所以四类行都仍可点进专辑页。

### 2. 标题按整串 32 列预算裁剪

宿主用 `maxLines: 1 + overflow: ellipsis` 渲染专辑名（`player_controls_bar.dart:131`、`desktop_now_playing.dart:532`），截断发生在**末尾**：60 列的 B 站标题会把 ` · N P` 整段吃掉，专辑行又变回「看不出有几 P」。

所以裁剪必须在插件侧做，而且**后缀宽度要先从预算里扣掉**：先量 ` · N P` 占几列，剩下的列数（再减掉省略号自己那 1 列）才给标题。只把标题裁到固定列数再拼后缀是不够的——那只是把后缀往前挪了几个字。只裁 `albumName`，不裁 `title`（标题列有 `flex: 3`，用户要读全）。

### 3. `albumSongs` 的 N 取 `#pages`

不是取过滤掉空 `cid` 之后的条数：专辑名描述的是「这支视频有几 P」，不是「这里能播几 P」。用 `#mappable` 会在有坏 P 时说小总数。

## 修掉的一个越界

第一版 `util.clip(album_base, 24) .. " · N P"` 在真机上仍被省略号吃掉后缀——裁到 24 列只是把后缀从第 54 列挪到第 25 列，宽屏专辑列照样放不下。

改成 `util.fit_label` 后，探针又抓到第二个 bug：`room` 整份交给了 `clip`，而 `clip` 的语义是「填满 limit 列，**然后**追加省略号」，省略号自己占 1 列，于是整串超预算 1 列：

```
{"budget":32,"suffixCols":8,"outCols":33,"out":"【无损音质】周杰伦歌曲精… · 100 P"}
```

而当时的 `T13#11` 逐字期望写的正是这个输出——**断言把 bug 钉成了正确答案**。本轮同时修了三处：`clip(source, room - 1)` 加 `room < 2` 的后缀优先分支、`T13#11` 期望值改成 11 字版、新增 `T13#14` 用 Dart 侧独立重算列宽断言整串 ≤ 32 列（N6 是把这一列还回去，红 2 条，证明新断言承重）。

## 已知限制（登记给宿主）

- **多 P 视频的列表行 `duration` 是整个合集的时长**：100 P 的合集行内写 `25142 s`（6:59:02），而 P1 只有 `228 s`（3:48）。进度条按合集长度走，P1 播完就换歌。修它需要逐行 `view`，而 `search` 一行的可支配预算已经是零（40 行/桶通过、50 行 408）。
- **`desktop_now_playing.dart:532` 的专辑链接没有空值兜底**（`now_playing_page.dart:1506` 有 `—`）。插件侧用「永不返回空 `albumName`」规避，但这是宿主健壮性缺口。
- **`Track` 没有 schema 版本**：`album-detail`（1 h）与 `playlist`（10 min）会短暂保留旧专辑名，升级后 1 小时内可能新旧混显。

## 升级方式

导入 `community.bilibili.music.zip`（ZIP 根目录为 `manifest.json`），或覆盖已有安装目录后重启 Lazer。

> 升级后如果正在播放页仍显示旧的泛名 `B站视频`，那是宿主缓存（`playback_cache.json` 里没有 schema 版本），清一次缓存即可。
