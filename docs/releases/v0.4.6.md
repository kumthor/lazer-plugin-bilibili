# v0.4.6 — 「N P」出现在你真正需要它的地方

v0.4.5 把后缀做对了，但**放错了地方**。

搜索行拿不到 P 数（B 站搜索接口的返回行没有 `videos`，实测 0/20），于是那里留了纯标题。而宿主把队列条目的 `album` 当成**只写一次**的字段：

```dart
// lib/logic/music/music_platform_state.dart:635
album: entry.album.isEmpty ? updated.album : entry.album,
```

这行的意思是：队列条目里的 `album` 非空，之后 `song()` 返回什么都不再进来。于是：

1. 搜索页 → 队列条目 `album = "【无损音质】周杰伦歌曲…"`（非空）
2. 用户点播放 → `hydrate()` → `song()` 返回 `album = "… · 100 P"`
3. 宿主合并 → `entry.album` 非空 → **丢弃** `updated.album`
4. 播放页显示纯标题，用户看不到有几 P

唯一能看到 ` · N P` 的地方，恰好是用户不需要它的地方。

## 改动

### 1. 搜索 / 收藏夹行改为留空 `albumName`

`song_rows(rows, { leaveAlbumBlank = true })`，两个调用方：`search()` 的 video 桶与 `favorites()` 的收藏夹走廊。收藏夹与 search 同族：真机 `fav_resources.json` 的 `_note` 写明 **0/19 既无 `videos` 也无顶层 `cid`**，处理必须一致。

留空不是「没有专辑」，是「还没问到」——空串让 `hydrate()` 有机会把它填成带后缀的那一版。

### 2. `song()` 提供升级源

```lua
parts = #pages > 0 and #pages or nil,
```

`view` 顶层的 `pages` 已在手，**零额外请求**。`song()` 本来就会被宿主在每条播放路径上调用（`_loadCurrentArtwork()` 有 6 处调用点），所以这个升级是免费的。

### 3. 有 `videos` 的行不受影响

热门 / 榜单 / 相关 / UP 投稿行仍当场写名字——它们有真实的 N，列表就是那个数字值得出现的地方。`T13#04b` 钉住这一条，防止本轮改动顺手把 v0.4.5 的可见性目标退回去。

## 为什么不能直接在搜索页补 N（实测否掉）

三条路都试过：

| 路径 | 结果 |
|---|---|
| 搜索接口本身带 P 数 | 66 个字段里**没有** `videos`、没有 `pages`；只有 `episode_count_text`（番剧集数文案，3/20 命中） |
| 逗号批量（`bvid=A,B`） | `pagelist` 与 `view` 都返回 `-400 请求错误` |
| 逐行补 `pagelist` | 搜索本身 697 ms，补 30 行再加 1 984 ms，**接近 3 倍**；且 `limit` 上限 100 时线性放大 |

顺带推翻了一个假设：原以为「20 个 pagelist 会撞 250k 指令预算」。实测 30 次 pagelist 全部通过——真正的 408 边界在**解码多少个字段**，不在发多少个请求。所以将来若愿意付 3 倍延迟，搜索页也能显示后缀；v0.4.6 走的是零额外请求的路。

**真机确认**：搜索 → 播放第 1 行（100 P 的《无损音质》合集）→ 正在播放页显示 `【无损音质】周杰伦歌曲… · 100 P`。

这一步是整个方案唯一的验收点：留空本身只是「删信息」，只有 `song()` 真的把后缀填回来，这条改动才有意义。

## 代价（已确认接受）

搜索与收藏夹行在宽屏（≥940px）列表里那一列专辑名变空白。原本那一列与标题列逐字重复，空白比重复干净；`albumKey` 来自 `albumId`、与名字无关，所以点按仍能进专辑页（`T13#03` 断言 `albumId == id`）。

## 一处登记

测试内嵌 manifest 停在 `0.4.5` 而安装版已是 `0.4.6`，`T6#21` 因此变红。这不是新引入的问题——改 `manifest.json` 时漏了测试文件里那份内嵌副本。`T6#21` 的职责正是钉住这两处一致（D12 的历史教训：内嵌副本曾停在 v0.1.0 且缺 `album/*`），所以它红了是**对的**：是这道门起了作用，不是测试坏了。已对齐为 `0.4.6`。

## 升级方式

导入 `community.bilibili.music.zip`（ZIP 根目录为 `manifest.json`），或覆盖已有安装目录后重启 Lazer。
